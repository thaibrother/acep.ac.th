เรียน ภราดา ดร.สุรกิจ ศรีสราญกุลวงศ์ ประธานคณะกรรมการบริหารมูลนิธิคณะเซนต์คาเบรียลแห่งประเทศไทย

จากการปฏิบัติหน้าที่และการศึกษาข้อมูลระยะกว่าหนึ่งเดือนที่ผ่านมา ตามคำสั่งของประธานมูลนิธิฯ และได้นำเสนอผลการศึกษาพร้อมเสนอแนวทางไปแล้ว ๒ ฉบับ

กระผมขอลำดับ ๓ ระยะของการฟื้นตัว พร้อมตัวเลขงบประมาณในแต่ละระยะ ตามความเร่งด่วน และตามลำดับการพลิกฟื้น ดังนี้

  • ระยะของการปิดจบ (หลักสูตร / นักเรียน / ครู / ผู้ปกครอง / หน่วยงานและสัญญาบริการ / อุปกรณ์ ฯลฯ)
  • ระยะของการคงประคอง (หลักสูตร / นักเรียน / ครู / ผู้ปกครอง / หน่วยงานและสัญญาบริการ / อุปกรณ์ / ห้องประกอบการ / อาคารสถานที่ ฯลฯ)
  • ระยะการเริ่มกิจการใหม่ (หลักสูตร / นักเรียน / ครู / ผู้ปกครอง / หน่วยงานและสัญญาบริการ / อุปกรณ์ / ห้องประกอบการ / อาคารสถานที่ ฯลฯ)

  1. เงินเดือนบุคลากรตลอดปีการศึกษา ๒๕๖๙
